# 증명도 문장으로 다시 써야 읽힌다

**출처**: Knuth, Larrabee, Roberts, 1989 — Mathematical Writing, Stanford CS Report STAN-CS-88-1193 / MAA Notes 14

---

## 발췌

> “sentences should flow smoothly when all but the simplest formulas are replaced by ‘blah’”

---

## 분석

이 발췌가 수식 글쓰기의 정전(canon)으로 통하는 까닭은 두 버전의 수식이 같기 때문이다. §2와 §3은 정확히 같은 정의, 정리, 증명 단계를 다룬다. 문장 결합 방식, 기호 배치, 서술 흐름만 다르다. 두 버전을 나란히 놓으면 "수식이 맞으면 글도 괜찮다"는 흔한 오해가 한 페이지에서 무너진다. 자기 증명 초고를 두고 "수식은 다 검증했다"라고 말하는 후배에게 같은 수식이 어떻게 전혀 다른 두 글이 되는지 보여 줄 수 있다.

§2 버전은 point 13의 "blah test"를 통과하지 못한다. 모든 displayed equation을 "blah"로 바꾸고 산문만 읽으면 문장이 끊긴다. 수식이 문장의 문법적 구성 요소가 아니라 삽입된 객체로 떠 있기 때문이다. 정의를 도입하는 문장이 콜론으로 끝나고 displayed equation 뒤의 문장이 새 주어로 시작하면, 수식을 뺐을 때 "Let X be defined as: . The function X then …"처럼 분절된다. §3 버전은 같은 displayed equation을 문장의 보어 자리에 놓아, 수식을 빼더라도 "Let X be defined as blah, so that the function X then …"처럼 이어진다. 같은 수학이 문장 결합 방식에 따라 다른 산문이 된다.

Point 5는 정리 진술의 자기완결성을 요구한다. §2의 정리는 앞 단락에서 정의한 기호 $S_q$, $p$ 등을 설명 없이 그대로 사용한다. 독자는 정리만 읽고서는 $S_q$가 무엇인지, $p$가 어떤 범위인지 알 수 없어 앞으로 돌아가야 한다. §3의 정리는 "where $q < p$ and $S_q$ denotes …"라는 짧은 어구를 넣어 같은 기호를 진술 안에서 정의한다. 길이는 한 줄만 늘었지만 정리를 따로 떼어 읽어도 뜻이 통한다. 정리를 점검할 때는 진술만 복사해 새 페이지에 놓고 단독으로 이해되는지 묻는다. 이해할 수 없다면 §3처럼 짧은 종속절로 모든 기호를 그 자리에서 정의한다.

Point 1은 인접한 기호 사이에 단어를 넣으라고 한다. §2에서 "$S_q$, $q < p$"처럼 두 수식이 쉼표 하나로 이어지면 독자는 둘이 같은 객체의 두 표현인지 독립된 두 조건인지 즉시 가르지 못한다. §3처럼 "$S_q$, where $q < p$"라고 "where" 하나를 넣으면 모호함이 사라진다. 토큰 하나만으로 해석의 갈림길을 없앨 수 있다. Knuth가 27개 항목 중 첫째로 이 원칙을 둔 까닭이다.

같은 단락에 여러 원칙이 동시에 적용된다는 점도 교육에 유리하다. Point 1(인접 기호 분리), point 2(기호로 문장 시작 금지), point 5(정리 자기완결성), point 10(수식 사이의 설명), point 11(정의를 보완적인 두 방식으로 제시), point 13(blah test), point 14(기호 일관성), point 16(중요한 수식의 표시)이 한 단락의 rewrite에 연쇄적으로 걸린다. 자기 증명 한 단락을 §3의 형식으로 다시 쓰면 이 원칙들을 함께 점검할 수 있다.

한국어 수학 글쓰기로 옮기면 위치 문제 하나가 추가된다. 영어의 "where", "such that"은 종속절을 뒤에서 끌어와 진술의 자기완결성을 채운다. 한국어는 SOV 어순이므로 종속절이 앞에서 와야 자연스럽다("$q < p$인 $S_q$에 대해, …"처럼). "단,"이나 "여기서"는 종속절 뒤에 추가 조건을 붙일 때 쓰는 어구지만, 정리 진술 안의 기호 정의는 한국어에서 영어처럼 뒤로 미루기보다 앞에 두는 편이 자기완결성을 더 잘 확보한다. 이 차이를 인지하지 못한 채 영어 rewrite 패턴을 그대로 한국어로 옮기면 어색해진다.

## 따라 쓰기 패턴

자기 증명의 한 단락은 세 가지로 점검한다. ① 모든 displayed equation을 "blah"로 바꾼 문장 골격만 읽는다. 산문이 흐르는가, 끊기는가? ② 정리 진술만 복사해 새 페이지에서 읽는다. 모든 기호가 그 자리에서 정의되는가? ③ "$x$, $y > 0$"이 아니라 "$x$, where $y > 0$"처럼 인접한 두 수식 사이에 단어가 있는가? 하나라도 실패하면 §3 버전의 문장 결합 방식으로 재배치한다.

한국어 증명 단락을 쓸 때는 정리 진술의 기호 정의 어구를 진술 앞에 두는 패턴이 자기완결성에 유리하다는 점을 기억해 둔다. "정리. $f$가 연속이고 $K$가 컴팩트일 때, $f$는 $K$ 위에서 균등연속이다"처럼 조건이 앞에 와야 한국어 어순이 살고, 동시에 진술이 단독으로 닫힌다.
